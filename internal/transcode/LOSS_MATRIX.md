# Loss matrix

Generated from the granular loss-key registry in `losses.go` by `go generate` —
see losses.go. Do not edit this file by hand; the drift test in
loss_matrix_drift_test.go proves it never drifts from the registry.

Every non-portable feature is gated by exactly one granular, direction-specific
loss key. The default strict policy rejects every loss; a mapping approves
individual keys via `-transcode-allow-loss`.
