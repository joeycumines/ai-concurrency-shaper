# Supporting documentation

## Freshness and liveness of docs/

This documentation does not make any guarantees about freshness or liveness.
While documents in this directory SHOULD be maintained and kept up to date, and
make an effort to avoid duplication where possible, consumers of this
documentation must remain wary that it may be out of date, and that the source
of truth is the code itself, along with the dedicated (minimal) "living
documentation", located in the root of the project.
